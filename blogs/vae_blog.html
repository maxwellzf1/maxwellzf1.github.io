Intro to VAE's

Apr 17, 2025

Hello everyone. Finals are coming up, so I've been prepping for one of my classes 10-708 Probabilistic Graphical Models (highly recommend btw). The class covers three main concepts of ML: representation, inference, and learning. My favorite part of the class were the sampling methods, like MCMC, rejection sampling, importance sampling. The second part of the class covers variational inference, which is a method to approximate posterior functions. I'm a bit more rusty on these topics, so I'll write a blog post to see how much I actually understand.

Variational Inference

When I first learned VI, the symbols made my head spin. It built on some entropy term, which I didn't know, and KL divergence, which I was very unfamiliar with. I talked for a few hours with ChatGPT, and I gained a little bit more intuition.

Recall one of the main ideas of ML: if we want to fit a model \(p\) to some data \(X\), we should try to maximize the log likelihood \(\sum_x \log p(x)\). Now here is the main idea of Variational Inference. Consider some latent variables \(z\). Now, from simple Bayes' Rule, we have that

\[ p(z | x) = \frac{p(x | z)p(z)}{p(x)} = \frac{p(x | z)p(z)}{\int_z p(x | z) p(z) dz} = \frac{p(x | z)p(z)}{Z} \]

where \(Z\) is the normalization constant (or partition function). If we want to find the posterior \(p(z | x)\), we need to compute the normalization constant, which requires us to compute a nasty integral, which is usually intractable. Thus, we devise a new strategy where we approximate \(p(z | x)\) using a distribution \(q(z | x)\) that is easier to compute. We can think of this as minimizing the KL divergence \(\text{KL}(q(z | x) || p(z | x))\).

Ok, so we have some idea of what we're trying to solve. Now, after some neat algebra, we have that

\[ \text{KL}(q(z | x) || p(z | x)) = \mathbb{E}_{q}[\log q(z | x)] - \mathbb{E}_{q}[\log p(z | x)] = \mathbb{E}_{q}[\log q(z | x)] - \mathbb{E}_{q}[\log p(z, x)] + \mathbb{E}_{q}[\log p(x)] \] \[ = \mathbb{E}_{q}[\log q(z | x)] - \mathbb{E}_{q}[\log p(z, x)] + \log p(x) \]

Thus, we get that

\[ \log p(x) = \text{KL}(q(z | x) || p(z | x)) + \mathbb{E}_{q}[\log \frac{p(z, x)}{q(z | x)}] \]

This tells us a few things. First, note that by definition of convergence, our KL divergence term must be non-negative, so we have that \(\log p(x) \geq \mathbb{E}_{q}[\log \frac{p(z, x)}{q(z | x)}]\). We now have a lower-bound on our log-likelihood. Second, note that if we try to maximize our log-likelihood, we are essentially trying to maximize the term on the right. But we are also trying to minimize the KL divergence term since we are trying to find a distribution \(q(z | x)\) that is close to \(p(z | x)\). Thus, we get that maximizing our log-likelihood is equivalent to maximizing the expectation term. This leads us directly to VAE's.

VAE's (Variational Autoencoders)

As a preliminary setup, we need to create some functions. If the setup is not very intuitive, don't worry and just try to follow along. We need a prior and and a likelihood that are simple and easy to sample from. Typically, we can just choose normal distributions.

Just like with any generative model, we want to construct a model \(p(x)\) that emulates the input distribution. Then, to generate a sample, we can sample from \(p(x)\). So now we're trying to construct a model such that \(\log p(x)\) is maximized. As we stated above, this is equivalent to maximizing \(\mathbb{E}_{q}[\log \frac{p(z, x)}{q(z | x)}]\). Let's first write this expectation in a different form. Note that \(\mathbb{E}_{q}[\log \frac{p(z, x)}{q(z | x)}] = \mathbb{E}_{q}[\log p(x | z)p(z)] - \mathbb{E}_{q}[\log q(z | x)] = \mathbb{E}_{q}[\log p(x | z)] - \text{KL}_{q}(q(z | x) || p(z))\). This form gives us some more intuition. If we want to maximize this term, then we want to maximize the expectation term and minimize the KL term.

Let's start with the expectation term. Intuitively, we are optimizing \(q\) and \(p\) so that we can sample from \(q\) using some \(x\) to get some variable in the latent space, and then reconstruct this \(x\) using \(p\) and our sampled \(z\). This is called the reconstruction term. If our expectation is high, this is telling us that \(q\) and \(p\) go hand in hand.

Now, looking at the KL term, we want our \(q\) to be close to our prior \(p(z)\). We can treat this as some regularization term so that we don't learn some crazy complicated distribution \(q (z | x)\). Now we have the intuition of what we want to do, so now let's actually try to optimize this loss more rigorously.

In ML, how do we optimize functions? Gradient descent. We can simply take the negative of the expectation and run gradient descent to minimize it. We have a few problems though. First, we're computing the gradient of the expectation term, which requires us to take the derivative of our distribution \(q\), which can be very difficult to calculate. Also, we're optimizing over multiple variables since we constructed our model \(p\) and created a distribution \(q\). This leads us to the idea of Expectation-Maximization.

Additional Thoughts on Latent Space

The idea of latent space was very abstract to me (since we never observe it), so I always thought this idea was some bs. However, after thinking about the latent space using classification tasks, it was much easier to visualize. I'll try to explain it how I understand it.

Suppose our task is to generate pictures of animals, and we are given a lot of labeled data. Then, we can think of our latent space as some representation of the animals. Try to visualize our latent space as several modes (like big hills). Now, the peak of each hill represents the point in the latent space that corresponds to a specific animal. If we have a perfect encoder (\(q\)) and a perfect decoder (\(p\)), then we should be mapping an image of a horse to the exact point in the latent space. This means that we should be mapping this \(x\) to the point \(z\) where the \(z\) corresponds to a horse. This is the highest point of the hill. Now, if our decoder is perfect, once it sees this \(z\), it should construct a beautiful image of a horse. This leads us to the idea of the latent space being some kind of representation of the data. If we want an image of half horse and half cat, then we can first find the top of the hill for a horse, then find the top of the hill for the cat, and then take the midpoint of these two points. This is exactly taking the midpoint of the means that we output from the neural network.

The idea of taking the midpoint is called latent space interpolation. I plan to run some experiments to see if my understanding is correct. Perhaps I will include it as an additional blog post.

Also, just some additional thoughts on the encoder-decoder architecture. When we train our encoders and decoders, we are trying to build this latent space and these hills and interpreting these hills as images. My professor once said that if you play tennis or chess against someone much better or much worse than you, you will never improve. You should be playing against someone with similar strength. I believe he was talking about GAN's, but the idea still applies. If your encoder is too good, then even if the decoder is kinda dogshit, it will still be able to reconstruct a good image. If your encoder is too bad, then regardless of how good the decoder is, the image will be mapped to some random point in the latent space, and the decoder will have no idea how to reconstruct the image. That's why we need the encoder and decoder to have similar strength. I hypothesize this impacts the initialization of these models, but I have yet to run my own tests, so I'm unsure.
