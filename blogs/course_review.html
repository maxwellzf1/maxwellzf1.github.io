Course Review

Fall 2025

✕ 15-281: Artificial Intelligence: Representation and Problem Solving

The content is extremely shallow. The purpose of the course is to serve as an introduction to AI, but the class glosses over most topics without ever explaining motivation. It makes it very difficult to understand what the professor is trying to accomplish or teach.

It does cover a wide range of topics, like probability, logic, PGM, RL, game theory, but I think it's better to take the classes that go more into depth for each of these topics. I believe this class is no longer offered at CMU.

♥ 15-418: Parallel Computer Architecture and Programming

Before coming to CMU, I thought computer science would be very hardware oriented since computer hardware is very intricate. However, the CS curriculum at CMU is extremely software oriented. The only course (that I've taken) that discusses hardware in the computer science department is 15-213, which gives a very brief overview of how processors and memory work.

This class forces you to think about how software directly affects hardware and programming around hardware limitations, like data bandwidth or small RAM space. Programming is done on the Gates clusters, which use NVIDIA RTX 2080 GPU's and Intel i7 CPU's. Programming assignments do not have hard thresholds and are mainly judged on your performance compared to your peers. To optimize your program, you usually need to run experiments on CPU processors, check how much data is in your working set, calculate the data transfer speed between CPU and GPU, and then decide if running an algorithm on CPU or GPU is more efficient. I found that doing these theoretical calculations that were surprisingly close to experimental results actually yielded benefits and helped us with our design choices. Also, the class gives some experience with low-level programming using C++ and CUDA, which could be beneficial in the workplace.

CMU Courses I Wish I Took

  • 15-410: Operating Systems
  • 15-411: Compiler Design
  • 15-888: Computational Game Solving
? 15-440 Operating Systems

This is widely regarded as the most difficult class at CMU. I felt that the course rigor at CMU was quite difficult, but there was definitely some room for more rigor. It would have been interesting to see how intense the course really is. Also, I believe that operating systems should be mandatory for all CS students (I guess 15-213 covers basic operating systems), and I think this class could definitely give deeper insights on systems in general.

? 15-441 Compiler Design

This is probably the second hardest course at CMU. Again with OS, I think this course would give deeper insights on systems in general. My partner for 15-418 took this class the previous semester, and he briefly mentioned a multi-coloring algorithm used for register allocation, which sounded pretty interesting.

? 15-888 Computational Game Solving

I enjoy playing games. This course is all about playing games and creating solvers for these games. The professor is also very well-known for creating Pluribus, which is one of the first Poker bots.
